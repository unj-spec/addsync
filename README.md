# WoW 애드온 매니저

**와우 애드온과 설정을 다른 PC로 그대로 옮기는 프로그램.**

집에서 쓰던 애드온 구성과 설정을, 다른 PC에서 클릭 몇 번으로 똑같이 만듭니다.
애드온 폴더뿐 아니라 **애드온 프로필·키바인드·매크로(WTF)** 까지 함께 옮깁니다.

## 받기

[Releases](https://github.com/unj-spec/wow-addon-manager/releases) 에서 받으세요.

| 파일 | 쓰임 |
|---|---|
| `WowAddonManager-Setup-x.x.x.exe` | 내 PC에 설치해서 계속 쓸 때 |
| `WowAddonManager-portable.exe` | **PC방·남의 PC** — 설치 없이 바로 실행 |

- 윈도우 10/11, 따로 설치할 것 없음 (.NET Framework 4.x 는 윈도우에 기본 포함)
- 새 버전이 나오면 프로그램이 알려주고, 버튼 하나로 업데이트됩니다

---

## 어디서든 쓰는 법

집에서 한 번 올려 두면, 다른 PC에서는 **프로그램 받기 → 구글 로그인 → 버튼 하나**입니다.

**집에서 (한 번)**

1. 프로그램 실행 → **클라우드** 탭 → 구글 로그인
2. **이 PC 상태를 올리기**

**밖에서 (매번)**

1. `WowAddonManager-portable.exe` 를 받아 실행 (설치 안 해도 됩니다)
2. **클라우드** 탭 → 구글 로그인
3. **드라이브에서 받아 설치**

그 PC의 와우를 알아서 찾고, 설치된 게임 버전에 맞춰 애드온과 개인 설정을 넣습니다.
설치 전에 무엇이 바뀌는지 먼저 보여주고, 원래 상태는 백업해 둡니다.

> **쓰고 나서 원래대로**: 남의 PC였다면 **백업** 탭에서 되돌리기를 누르세요.
> 설치 직전 상태로 복구됩니다.

## 쓰는 법

### 1. 애드온이 있는 PC에서 — 내보내기

1. 프로그램 실행 (와우 설치 위치는 자동으로 찾습니다)
2. 왼쪽에서 옮길 **버전**을 고릅니다 — 정식 서버, 클래식 등
3. **내보내기** 탭 → 저장 위치를 USB나 클라우드 폴더로 지정
4. **내보내기 시작**

저장 위치에 이렇게 만들어집니다:

```
_retail_-AddOns.zip      애드온 전체
_retail_-WTF.zip         설정 (애드온 프로필·키바인드·매크로)
manifest.json            애드온 목록과 버전 기록
```

### 2. 다른 PC에서 — 설치

1. 프로그램 설치 후 실행
2. **설치** 탭 → 가져올 폴더 지정 (USB나 같은 클라우드 폴더)
3. 왼쪽에서 설치할 버전 선택 → **설치 시작**

끝입니다.

> 구글드라이브·OneDrive 폴더로 내보내 두면 USB도 필요 없습니다.

## 화면

| 탭 | 하는 일 |
|---|---|
| **내보내기** | 이 PC의 애드온과 설정을 한 폴더에 담습니다 |
| **설치** | 담아 둔 폴더를 이 PC에 그대로 설치합니다 (설치 전 미리보기) |
| **애드온 목록** | 설치된 애드온의 이름·폴더·버전·출처를 봅니다 (검색 가능) |
| **백업** | 설치 전에 자동으로 뜬 백업을 보고, 그때 상태로 되돌립니다 |
| **클라우드** | 구글 드라이브에 올리고 받습니다 |

단축키: `F5` 와우 위치 다시 찾기 · `Esc` 닫기

## 바뀐 것만 다시 묶습니다

애드온을 zip 하나로 통째 묶지 않고 **애드온 폴더마다 따로** 묶습니다.
두 번째 내보내기부터는 파일 수·크기·수정 시각을 비교해 **바뀐 애드온만** 다시 압축합니다.

실제 측정값 (애드온 56개, 330MB):

| | 걸린 시간 |
|---|---|
| 처음 내보내기 | 9.6초 |
| 그대로 다시 내보내기 | **0.3초** |
| 애드온 1개 수정 후 | **1.1초** (1개만 재압축) |

CurseForge로 애드온 몇 개를 업데이트한 뒤에도 몇 초면 끝나고, 클라우드에도 바뀐 파일만 올라갑니다.

> 파일을 고쳤다가 되돌리는 식으로 크기와 시각이 우연히 같아지는 경우가 걱정된다면
> **정밀 검사**를 켜세요. 파일 내용까지 읽어 비교합니다(느립니다).

## 구글 드라이브 연동

**클라우드** 탭에서 구글에 로그인하면 내보낸 꾸러미를 드라이브에 올리고 받을 수 있습니다.
드라이브 앱을 깔 수 없는 PC에서도 됩니다. 바뀐 파일만 주고받습니다.

권한은 `drive.file` — **이 프로그램이 만든 파일만** 접근합니다. 사용자의 다른 드라이브 파일은 보지 않습니다.

### 처음 한 번만 — OAuth 클라이언트 만들기

소스에서 직접 빌드해 쓰는 경우, 구글 클라이언트 ID를 본인이 만들어 넣어야 합니다.

1. [구글 클라우드 콘솔](https://console.cloud.google.com) → 새 프로젝트
2. **API 및 서비스 → 라이브러리** → `Google Drive API` 사용 설정
3. **OAuth 동의 화면** → 외부 → 앱 이름·지원 이메일 입력
4. **사용자 인증 정보 → OAuth 클라이언트 ID** → 유형 **데스크톱 앱**
5. 받은 값을 [src/AppInfo.cs](src/AppInfo.cs) 의 `GoogleClientId`, `GoogleClientSecret` 에 넣고 다시 빌드

데스크톱 앱의 보안 비밀번호는 구글 설계상 공개되는 값입니다. 실제 보호는 PKCE가 합니다.

## 옵션

| 옵션 | 설명 |
|---|---|
| 개인 설정도 함께 | WTF 폴더 전체 — 아래 **무엇이 따라가나** 참고. 기본 켜짐 |
| 그래픽·해상도 설정까지 그대로 | 끄면 `Config.wtf` 에서 **그래픽 줄만** 빼고 나머지는 전부 가져갑니다. **모니터가 다르면 끄세요.** 기본 꺼짐 |
| 설치 전에 지금 상태를 백업 | `내 문서\WowAddonManager\backup\<날짜-시간>\` 에 zip 보관. 기본 켜짐 |
| 기존 애드온을 모두 지우고 설치 | 두 PC를 완전히 똑같이 맞출 때만. 기본 꺼짐 |

## 무엇이 따라가나

**따라갑니다**

- 애드온 폴더 전체 (`Interface\AddOns`)
- 애드온 설정 — 계정 공용 + 캐릭터별 `SavedVariables`
- **키바인드**, **매크로**(계정/캐릭터), **인터페이스 편집 모드 배치**
- 대화창 설정, 캐릭터 목록 순서, 게임패드 설정
- `Config.wtf` 의 개인 설정 — 사운드 볼륨, 이름표, 파티창, 카메라 거리,
  마우스 감도, 전투 로그, 추적 정보 등

**빠집니다**

- `Config.wtf` 의 **그래픽·해상도·하드웨어 설정** — 화질, 그림자, 시야 거리,
  해상도, 전체화면 모드, 수직 동기화, UI 크기, 밝기·대비, 오디오 출력 장치 이름
  (PC마다 달라야 하는 값들입니다. `그래픽·해상도 설정까지 그대로`를 켜면 이것도 갑니다)
- `*.old`, `*.bak`, `cache.md5` — 와우가 다시 만드는 백업/캐시

> 실제 파일로 확인한 수치: `Config.wtf` 178줄 중 개인 설정 86줄은 가져가고,
> 그래픽·하드웨어 92줄만 걸러냅니다.

## 알아둘 것

- **와우를 완전히 종료한 상태에서** 설치하세요. 실행 중이면 프로그램이 막습니다.
- 기본 설치는 **덮어쓰기 + 기존 유지**입니다. 그 PC에만 있던 애드온은 지우지 않습니다.
- **개인 설정이 붙는 조건**: WTF 는 `WTF\Account\<계정번호>\<서버>\<캐릭터>` 구조입니다.
  **같은 배틀넷 계정**으로 접속하면 애드온 설정이 그대로 붙습니다.
  계정이 다르면 설치 탭에 **계정 폴더 번호 맞추기** 선택지가 자동으로 나타납니다.
- 복사에서 빠지는 것: `*.old`, `*.bak`, `cache.md5` — 와우가 다시 만듭니다.
- 애드온 **버전은 내보낸 시점 그대로**입니다. 최신 버전으로 갱신하는 기능은 없습니다.
  옮긴 뒤 CurseForge 로 업데이트하면 됩니다. ([PLAN.md](PLAN.md) 에 이유)
- 서명되지 않은 프로그램이라 윈도우 SmartScreen 이 처음 한 번 경고할 수 있습니다.
  `추가 정보` → `실행`. 미덥지 않으면 아래처럼 직접 빌드해서 쓰세요.

## 직접 빌드하기

```bat
build.cmd
```

윈도우에 기본 포함된 .NET Framework 컴파일러(`csc.exe`)만 씁니다. Visual Studio 나 .NET SDK 는 필요 없습니다.

설치 파일까지 만들려면 [Inno Setup 6](https://jrsoftware.org/isdl.php) 를 설치한 뒤:

```bat
tools\build-installer.cmd
```

### 구성

```
src\            C# 소스
                WowCore   와우 탐지 · .toc 파싱 · zip · 그래픽 설정 필터
                Sync      증분 내보내기 · 설치 · 미리보기 · 백업
                GoogleDrive  OAuth(PKCE) + Drive v3
                Json      의존성 없는 JSON 파서
                Theme / MainForm / PreviewForm   화면
                Updater   프로그램 자동 업데이트
tools\          아이콘 생성, 설치 파일 빌드
scripts\        같은 기능의 PowerShell 버전 (자동화·예약 실행용)
installer.iss   Inno Setup 설치 스크립트
```

## 자동화

`scripts\` 에 같은 기능의 PowerShell 버전이 있습니다. 작업 스케줄러에 걸어 매일 자동으로 내보낼 수 있습니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Export-Addons.ps1 -Output "G:\내 드라이브\wow-addons"
```
